2026052606:
    - Eixo self-enrollment URL is now the canonical Moodle landing page
      (/enrol/index.php?id=<courseid>) instead of being read from
      {role_names}.name. The previous implementation overloaded the per-
      context role-name override field as a URL store, which:
        * Required admins to remember to set the override per Eixo (no UI
          hint pointed at it), silently falling back to ?redirect=0 (home)
          when missing.
        * Was attacker-controllable by anyone with moodle/role:manage in
          the context — mitigated previously with clean_param(PARAM_URL)
          but still fundamentally a misuse of the field.
        * Bypassed Moodle's standard enrolment landing page (which knows
          how to render self, payment, cohort, etc.).
