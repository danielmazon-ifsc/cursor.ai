# Banco de Respostas PDI

Documentos gerados a partir do arquivo original *Banco de Respostas - PDI*.

## Arquivos

| Arquivo | Descrição |
|---------|-----------|
| `Banco_de_Respostas_PDI_Reorganizado.docx` | Banco reorganizado em 8 categorias, com títulos descritivos (sem pergunta) e campo “Quando usar” |
| `Relatorio_Melhorias_Banco_Respostas_PDI.docx` | Relatório de melhorias por item original + prioridades |

## Categorias

1. **Inscrição e Elegibilidade** — critérios, inscrição, SIAPE, comprovantes
2. **Gestão de Vínculo e Cancelamento (PDI-DEX)** — encaminhamentos internos de RH/vínculo
3. **Acesso à Plataforma e Suporte Técnico** — erros, inconsistências, uso do ambiente
4. **Certificação, Progresso e Comprovação** — certificado, Integra/Moodle, comprovação parcial
5. **Palestras e Sala de Conferências** — liberação e acompanhamento de palestras
6. **Avaliações, Notas e Tentativas** — nota mínima, recuperação, questionários
7. **Plano de Estudos e Materiais Didáticos** — plano 12/24 meses e e-books
8. **Sobre o Programa e Dúvidas Gerais** — institucional, canal, carteira, gamificação, licenças

## Regenerar

```bash
python3 scripts/gerar_banco_pdi.py
```
