2026052609:
    - Performance + robustness sweep on the renderer:
        * Dropped renderer::get_module_name() and replaced its only call
          site with $mod->modname. The cm_info object already carries the
          module name as a string, so we no longer issue one extra
          {modules} SELECT per course module per page render (was N+1 on
          every Eixo page; an Eixo with 5 sections × 3 CMs cost 15 extra
          round-trips for nothing).
        * Hardened strip_letters(): now also strips whitespace, so a
          shortname like "Eixo 1" (with a space) produces "1" instead of
          " 1". The latter would have leaked a space into the generated
          DOM id (course- 1-window-5), which is invalid HTML and breaks
          any #id CSS selector that targeted it. The mapping for
          build_avaliacao_reacao_mural already trim()'d defensively, but
          the DOM id itself was still leaking the space.
    - lib.php: get_first_not_enroled_course_id() now gates its
      studypace::is_enroled() call behind class_exists(). If
      local_studypace is uninstalled (impossible in normal deploys but
      possible in fragmented dev setups) the home page now falls back
      to is_enrolled() from core instead of fatalling.

2026052608:
    - Fixed double-navigation bug introduced by 2026052607's server-side
      mural rendering. The .mural-aviso anchor is now a child of
      .interactive-area, so its click bubbles up to the section click
      handler. Without a guard, the user got the avaliação opened in a
      new tab AND the current tab navigated to the section content (or
      the section modal appeared). format-specialization.js now bails
      out of the section click handler when the click originated inside
      .mural-aviso, letting the anchor's native target="_blank"
      behaviour be the only navigation.
    - JS file is loaded with ?v=<pluginversion> by format.php, so
      bumping the plugin version is what invalidates the cached copy
      in the browser; an explicit purge is no longer required for this
      change to land for repeat visitors.
