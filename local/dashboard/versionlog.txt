2026052642:
    - Ranking-position scalability fix (critical for large sites). The per-user
      dashboard widget used to run a site-wide {coin_stack} aggregate on every
      render, cached only per-user — so on a 10k-student site a login burst
      stampedes the DB with thousands of identical full-table aggregations.
      The coin-total distribution is now computed ONCE site-wide and cached
      (key 'distribution', TTL 300s); each user's position is derived from it
      with an O(log n) binary search plus one cheap indexed lookup of their own
      total. Same "1224" ranking semantics. The 'coinranking' cache TTL moved
      from 60s to 300s accordingly.
